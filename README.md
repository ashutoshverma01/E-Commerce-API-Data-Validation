# E-Commerce API Data Validation using Postman

## Project Overview
This is a final year project on **API Data Validation** of an E-Commerce system using Postman.

## API Used
- Fake Store API (https://fakestoreapi.com)

## Modules Tested
- 01_Products
- 02_Cart
- 03_Users
- 04_Auth
- 05_Negative_Tests

## Validations Performed
- Status Code validation (200, 201, 400, 401, 404)
- Response Time validation
- Content-Type validation
- Response Body structure validation
- Required fields validation
- Data type validation

## How to Use this Collection
1. Download the `.json` file from this repository
2. Open Postman
3. Click **Import** → select the downloaded JSON file
4. Select the environment (if available)
5. Run individual requests or use Collection Runner
